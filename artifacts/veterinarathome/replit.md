# ВетДом — Ветеринар на дом

Платформа вызова ветеринара на дом (аналог Яндекс Го, но для ветеринарных услуг).

## Архитектура

Три продукта на общем бэкенде:

| Продукт | Папка | Описание |
|---|---|---|
| Клиентский сайт | `client/` | Заказ ветеринара на дом |
| Приложение для ветеринаров | `vet/` | Приём и выполнение заказов |
| CRM / Админ-панель | `admin/` | Управление платформой |

Бэкенд: `server/` — Express + TypeScript + PostgreSQL

## Запуск

```bash
npm run dev
```

Запускает бэкенд (порт 3001) и клиентский сайт (порт 5000) одновременно.

## Стек

- **Backend**: Node.js + Express + TypeScript + PostgreSQL
- **Frontend**: React + TypeScript + Vite + Tailwind CSS
- **Auth**: JWT (собственная система)
- **База данных**: Replit PostgreSQL (встроенная)

## User preferences

- Язык интерфейса: русский
- Дизайн: профессиональный, современный (цвет — зелёный/бирюзовый)
