Keep an automatic visual demonstration for newly created pending orders: nearby veterinarians receive the request, one accepts it, and the status progresses through found, en route, arrived, appointment, and completed.

**Why:** The user tested this behavior and explicitly confirmed that the animated search, map visualization, veterinarian card, and automatic status sequence work as intended.

**How to apply:** Preserve this demonstration when changing order tracking. Production status updates may later come from real veterinarian/admin workflows, but the product must retain an easy way to demonstrate the complete customer experience.
